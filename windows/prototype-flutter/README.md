# Prototype V0 — Flutter

Objectif : valider sur le matériel de l'église (cahier, section 8) :
- deux fenêtres (opérateur + projection plein écran) ;
- texte net avec ombre et contour ;
- vidéo en boucle fluide ;
- démarrage rapide (< 5 s).

## Prérequis

- Flutter 3.19+ avec le support Windows activé (`flutter config --enable-windows-desktop`)
- Visual Studio 2022 avec la charge « Développement Desktop en C++ »

## Lancer

```bash
flutter pub get
flutter run -d windows
```
