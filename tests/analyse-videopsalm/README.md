# Analyseur de la bibliothèque VideoPsalm (L0)

Outil à écrire : lit un recueil de chants et une Bible de la bibliothèque VideoPsalm de l'église, **en lecture seule**, et décrit leur structure dans `docs/format-videopsalm.md`.

Règles : aucun fichier de la bibliothèque dans le dépôt (cahier, section 11) ; on ne publie que la description du format et des extraits sans droits.
